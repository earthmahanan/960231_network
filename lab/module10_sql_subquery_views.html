Subqueries & Views — A Query Inside a Query

Same shop, same tables — now you'll ask questions that need an answer before they can be answered.

Student info

🪆
Think Russian nesting dolls. A subquery is a query hiding inside another query — the inner one has to run first before the outer one can use its answer ("what's the average price?" before "which products cost more than that?"). A view is just a subquery you liked enough to give a name and save — so instead of retyping it everywhere, you SELECT * FROM your_saved_query like it's a real table. Keep that picture in your head for every exercise below.
